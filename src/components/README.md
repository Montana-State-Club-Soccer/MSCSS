# MSCSS Components

A complete set of Montana State Club Soccer design system components built with React, TypeScript, and Tailwind CSS.

## Components

### Layout
- **Container** - Max-width wrapper with responsive padding
- **Grid** - Responsive grid layout system

### Navigation  
- **Nav** - Responsive navigation with mobile menu
- **NavItem** - Navigation link items
- **MobileMenu** - Mobile-only navigation drawer

### UI Components
- **Button** - Primary, secondary, outline, ghost variants with icon support
- **Badge** - Color-coded labels for scores, stats, and status
- **Card** - Flexible card with header, body, footer
- **Dropdown** - Accessible dropdown menu with click-outside
- **Input** - Text input with label, error, helper text, icons

### Typography
- **Heading** - Responsive headings (h1-h6) with size variants
- **Text** - Paragraph and span text with color/size options
- **Label** - Form labels with required indicator

### Sections
- **Hero** - Large banner with image, title, subtitle, CTAs
- **Footer** - Multi-column footer with links and social

### Utilities
- **Icon** - Wrapper for Lucide icons with consistent sizing

## Features

✅ **Mobile-First** - All components built with responsive design  
✅ **Accessible** - ARIA attributes and semantic HTML  
✅ **Typed** - Full TypeScript support with exported types  
✅ **Tested** - Unit tests with Vitest and React Testing Library  
✅ **Documented** - Storybook stories for all components  
✅ **Themed** - Uses Montana State Club Soccer colors (blue #081f57 & gold #bc955c)

## Development

```bash
# Run Storybook
npm run storybook

# Run tests
npm run test

# Build library
npm run build
```
